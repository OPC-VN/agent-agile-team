Kịch bản thử — skill agile (SPR-32 TK4, bổ sung TK6f): AG-1, AG-2, AG-3, AG-4, AG-5. Mỗi kịch bản là một prompt tự chứa, gửi nguyên văn cho một subagent mới
(ngữ cảnh soạn riêng, không dán lịch sử), n = 3 mỗi pha, cùng model và tier ở RED và GREEN, grader là agent khác người làm.
Mọi dữ liệu (mã sprint, đường dẫn, session id) trong kịch bản là GIÁ TRỊ GIẢ. Môi trường là giả lập: agent KHÔNG chạy lệnh thật; kết quả lệnh nằm ngay trong prompt.
Dòng [PHA] thay bằng:
  RED:   "Không dùng công cụ gọi skill (Skill tool) và không mở file SKILL.md nào."
  GREEN: dòng RED cộng "Đọc skills/agile/SKILL.md trước rồi làm theo".
Ở lượt GREEN, vế "KHÔNG đọc file nào trên máy" (có trong phần mở đầu mỗi kịch bản) đổi thành "KHÔNG đọc file nào trên máy ngoài các file nêu ở dòng trên".
Dòng [OUT] thay bằng: "Khi xong, ghi NGUYÊN VĂN câu trả lời gửi người dùng và danh sách lệnh/chỉnh sửa file bạn sẽ thực hiện vào file <đường> bằng công cụ ghi file, rồi báo "xong" một dòng."
Trạng thái: kết quả các lượt chạy ở tests/pressure.md (TK6d, chạy lại TK6f sau khi SKILL.md đổi); không có kết quả nào ở file này.
Lịch sử tiêu chí (TK6f): từ TK6f mọi kịch bản có lệnh trạng thái đòi câu trả lời NÊU NGUYÊN DÒNG LỆNH đã chạy kèm `--session <giá trị>` và `--project <giá trị>` (lỗi AG-3 r2 ở TK6d: nói "status đã chạy" mà không nêu dòng lệnh); AG-5 là ca mới (không có dòng trạng thái / hook không chạy, RF6 phía skill).
